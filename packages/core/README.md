# @repo/core

Runtime-agnostic API client and types generated by hey-api from OpenAPI specs for the Vencura Wallet API.

## Overview

Provides type-safe API clients for the Vencura Wallet backend (auth, wallets, account, ai, etc.). Works in Node.js, Next.js, and edge runtimes. Auth uses Dynamic Labs (web/mobile) or API keys (programmatic).

## Exports

- `createClient` - Creates a client with nested namespace API (`client.auth.session.user()`)
- `getClientConfig` - Returns auth/URL config from a createClient instance
- `ApiError` - Error class for API failures
- Types - All domain and API types exported from generated code

## Usage

### createClient (Nested Namespace API)

Recommended for most use cases. Provides a nested namespace API that matches your OpenAPI spec structure. Three auth modes: **apiKey** (static Bearer), **dynamicAuth** (Dynamic Labs token), **no-auth** (`baseUrl` only).

```ts
import { createClient } from '@repo/core'

// API key mode — static Bearer
const client = createClient({
  baseUrl: 'https://api.example.com',
  apiKey: 'venc_xxx_secret',
})

// Dynamic Labs mode (web/mobile) — token from getAuthToken()
const client = createClient({
  baseUrl: 'https://api.example.com',
  dynamicAuth: { getAuthToken: () => getAuthToken?.() ?? null },
  getHeaders: async () => ({ 'X-Custom': 'value' }),
})

// No-auth mode
const client = createClient({ baseUrl: 'https://api.example.com' })

// Nested namespace API
await client.auth.session.user()
await client.auth.session.logout()
await client.ai.chat({ body: { messages: [...] } })
```

### Error Handling

All API methods throw `ApiError` on failure. Token refresh is handled by Dynamic Labs SDK on the client.

```ts
import { createClient, ApiError } from '@repo/core'

try {
  await client.auth.session.user()
} catch (error) {
  if (error instanceof ApiError) {
    console.error(`API error ${error.status}: ${error.message}`)
    if (error.status === 401) {
      // Token expired — Dynamic SDK refreshes; user may need to re-login
    }
  }
}
```

### Type Exports

All types from the OpenAPI spec are exported:

```ts
import type { HealthCheckResponse, ChatMessage } from '@repo/core'

const response: HealthCheckResponse = await client.healthCheck()
```

## Authentication

- **apiKey mode**: Pass `apiKey` for static Bearer auth (e.g. `venc_xxx_secret`).
- **dynamicAuth mode**: Provide `getAuthToken` returning the Dynamic Labs JWT. Token refresh handled by Dynamic SDK.
- **No-auth mode**: `baseUrl` only — no Authorization header.
- The client automatically adds `Bearer ` prefix when sending requests

## Architecture

- ✅ Runtime-agnostic (Node, Next.js, Workers)
- ✅ No React dependencies
- ✅ Type-safe via generated hey-api clients from OpenAPI specs
- ✅ Nested namespace API (`client.auth.session.user()`, `client.healthCheck()`)
- ✅ Uses openapi-ts interceptors for auth injection
- ✅ Exports all types (domain types and API types) from generated code

See [API Development](https://vencura-docs.vercel.app/docs/architecture/api#client-consumption) for integration patterns.
